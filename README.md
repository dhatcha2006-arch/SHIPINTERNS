# SkillForge – Internship & Training Academy Management Platform

SkillForge is a production-grade, enterprise-ready internship and training academy management platform connecting students, mentors, corporate training partners, and administrators.

## Technology Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5.3, Vanilla JavaScript (ES6+), Jinja2 Templates, Fetch API
- **Backend:** Python Flask REST APIs
- **Design Philosophy:** Clean, accessible, Human-crafted UI (Zero AI-slop, calm palette, 4px grid)
- **Primary Contributor:** dhatcha2006 (Lead Frontend Developer)

## Modules
1. Academy Public Website (Home, About, Programs, Contact, Careers)
2. Internship Catalog & Status Tracking
3. Authentication & Security (Login, Register, Password Recovery)
4. Student Command Center & Skill Passport
5. Course Catalog & Interactive Lesson Player
6. Learning Roadmap & Milestone Graph
7. Assignment Submissions & Coding Assessment Environment
8. Timed Quizzes & Examination Engine
9. Mentor Allocation & Evaluation Feedback
10. Live Projects, Agile Kanban & GitHub PR Reviews
11. Virtual Classrooms (Zoom & Google Meet Schedulers)
12. Attendance Dashboard & Daily Work Standup Reports (DWR)
13. Cryptographic Certificate Verification Engine
14. Admin Governance & HR Corporate Recruitment Portals
